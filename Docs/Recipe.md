# Техкарта: Дождевая каша с томленой говяжьей щекой в мясном соусе

> Горячее мясное блюдо ресторанного меню.  
> **Выход порции:** 410 г  
> **Особенность:** блюдо готовится в два этапа — заготовка щек в цеху и финальная сборка каши на кухне ресторана.

---

### Этап 1. Заготовка: томленые говяжьи щеки (цех)

Щеки зачищаются и томятся при низкой температуре до распадающихся волокон.

| Ингредиент | Вес / Объем |
| :--- | :--- |
| Говяжьи щеки (охлажденные) | 180 г |
| Соус мясной демигляс | 50 мл |
| Морковь и репчатый лук | по 20 г |
| Специи (соль, тимьян, перец) | по вкусу |

**Как готовить:**
1. Обжарить зачищенные щеки на сковороде до золотистой корочки.
2. Переложить в лоток с овощами, залить мясным соусом и специями.
3. Отправить томиться в печь при 85 °C на 8 часов. Готовая щека на выходе — 120 г.

---

### Этап 2. Сборка и отдача блюда (ресторан)

Каша варится «из-под ножа», щека глазируется в соусе прямо перед отдачей гостю.

| Состав на порцию | Количество |
| :--- | :--- |
| Готовая томленая щека | 120 г |
| Крупа птитим («дождевая») | 75 г |
| Мясной бульон для варки | 140 мл |
| Мясной соус на глазировку | 40 мл |
| Сливочное масло 82.5% | 20 г |
| Сыр твердый (пармезан) | 10 г |
| Микрозелень для декора | 5 г |

**Технология отдачи:**
1. Крупу птитим сварить в горячем бульоне до мягкости (около 8–9 минут).
2. Затянуть готовую кашу сливочным маслом и тертым сыром для кремовой текстуры.
3. Томленую щеку прогреть на сковороде с соусом демигляс до густого глянца.
4. В глубокую тарелку выложить кашу, сверху положить глазированную щеку, полить оставшимся соусом и украсить микрозеленью.
