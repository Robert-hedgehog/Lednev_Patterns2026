# Описание доменных сущностей сети ресторанов «Ромашка»

| Наименование сущности | Описание | Связи с другими сущностями |
| :--- | :--- | :--- |
| **Единица измерения** (`measurement_unit`) | Базовый уровень для учета веса, объема или количества (кг, литры, штуки). | Входит в `nomenclature` и `technological_card`. |
| **Деньги** (`money`) | Финансовая сущность для расчета стоимости, оплаты заказов и заработной платы. | Используется в `financial_document`, `work_schedule`, `delivery_order`. |
| **Ингредиент** (`ingredient`) | Исходное сырье или полуфабрикат с указанием количества и единицы измерения. | Инкапсулирует `measurement_unit`; входит в `technological_card` и `nomenclature`. |
| **Номенклатура** (`nomenclature`) | Товарно-материальная ценность (сырье, полуфабрикат, готовое блюдо, упаковка). | Входит в `nomenclature_group`, содержит `measurement_unit`. Участвует в `storage`, `technological_card`, `inventory`. |
| **Группа номенклатуры** (`nomenclature_group`) | Категория товаров для классификации и проведения частичной инвентаризации. | Объединяет элементы `nomenclature`. |
| **Блюдо** (`dish`) | Готовая позиция меню, состоящая из ингредиентов и рецептуры. | Разновидность `nomenclature`; ссылается на `technological_card`. |
| **Технологическая карта** (`technological_card`) | Рецептура блюда или полуфабриката (состав сырья, граммовка, шаги). Допускает вложенность других техкарт. | Ссылается на `nomenclature` (сырье и результат); участвует в `production_order`. |
| **Склад** (`storage`) | Место хранения сырья, заготовок и продукции в ресторане или производственном цеху. | Привязан к `restaurant` или `production_workshop`; хранит `nomenclature`. |
| **Ресторан** (`restaurant`) | Филиал сети (10 точек: зал, доставка, комбинированный). Работает с 10:00 до 22:00. | Связан с `storage`, `employee`, `delivery_zone`. Формирует `replenishment_order`, принимает `delivery_order`. |
| **Производственный цех** (`production_workshop`) | Круглосуточное подразделение для централизованной заготовки и хранения мяса/молока. | Содержит `storage`; выполняет `production_order` и отгружает по `replenishment_order`. |
| **Район доставки** (`delivery_zone`) | Географический район с фиксированной стоимостью доставки. | Связан с `delivery_order` и ближайшими `restaurant`. |
| **Адрес доставки** (`delivery_address`) | Гео-атрибут местоположения клиента для выполнения заказа. | Инкапсулируется в `delivery_order`. |
| **Контрагент** (`contractor`) | Внешнее юридическое или физическое лицо (поставщик, клиент). | Связан с `financial_document` и `contract`. |
| **Сотрудник** (`employee`) | Работник компании. Указывается во всех документах учета. | Входит в `employee_category`, работает в `restaurant` или `production_workshop`, связан с `work_schedule`. |
| **Категория персонала** (`employee_category`) | Справочник категорий (производство, обслуживание, управление). | Объединяет `employee`. |
| **График работы / Смена** (`work_schedule`) | Учет смен и рабочего времени с начислением двойного тарифа за переработку. | Привязан к `employee` и подразделению. |
| **Заказ на доставку** (`delivery_order`) | Заказ клиента, поступающий в ближайший ресторан доставки. Включает блюда и упаковку. | Привязан к `delivery_zone`, `restaurant`, `employee`. Содержит позиции `nomenclature`. |
| **Заказ на пополнение склада** (`replenishment_order`) | Заявка ресторана в производственный цех на поставку заготовок и продуктов. | Связывает `restaurant`, `production_workshop` и ответственного `employee`. |
| **Заказ на производство** (`production_order`) | Внутреннее задание цеху на изготовление партии заготовок или блюд по техкарте. | Ссылается на `technological_card`, `production_workshop` и `employee`. |
| **Инвентаризация** (`inventory`) | Документ пересчета остатков (плановая ежемесячная или частичная по группе). | Ссылается на `storage`, `nomenclature_group` и `employee`. |
| **Утилизация / Списание** (`disposal_document`) | Документ списания продукции со склада (режимы: «с блокировкой» или «под сальдо»). | Ссылается на `storage`, `nomenclature` и `employee`. |
| **Финансовый документ** (`financial_document`) | Учет движения денег (поступление/списание) по типам оплаты (наличные, безнал). | Ссылается на `contractor` и `employee`. |
| **Контракт** (`contract`) | Договор, определяющий условия работы с контрагентами. | Инкапсулирует `contractor` и `employee`. |
| **Организация** (`company`) | Юридическое лицо ООО «Ромашка». | Объединяет все `restaurant`, `production_workshop`, `storage` и `employee`. |
